Blessing recordings — checklist

Every line of Hebrew in the app that can have a recording, with the file name it needs. Until a line has its recording, the app's speaker button reads it with the visitor's device voice (when the device has a Hebrew voice).

How to record
  1. Record each line on its own — a phone's voice-memo app is fine. A quiet room, phone about a hand's width away, a calm and clear pace.
  2. Say God's name (written ה׳) as "Adoshem", as in practice recordings.
  3. Name each file exactly as shown (for example b-hamotzi.m4a). .m4a or .mp3 both work.
  4. Send the files to Claude in this project (or put them in the audio/ folder and list them in js/audio.js). Each one shows up in the app as soon as it's added.
